Deploy

当前服务器部署建议

可行。因为它是纯静态站，只要你的服务器能提供 HTTP 服务，就能部署。

Recommended

Nginx 方式

把 `baobaoWEB` 目录内容放到站点根目录，例如 `/var/www/baobao`，再把域名指向这台服务器即可。

server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    root /var/www/baobao;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
Simple

临时测试

如果只是先内网或临时访问，也可以直接在服务器目录下运行简单静态服务，但正式上线还是建议 Nginx。

cd /path/to/baobaoWEB
python3 -m http.server 8080
