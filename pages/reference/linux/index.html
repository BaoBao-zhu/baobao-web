Linux 常见命令速查

这页优先收录真正高频的排查、文件、日志和环境相关命令。目标不是全，而是遇到问题时能最快找到入口。

文件与目录

ls -lah
find . -maxdepth 2 -type f
du -sh *
tree -L 2
pwd
realpath file.txt

进程与端口

ps aux | grep python
top
lsof -i :8000
ss -lntp
kill -9 PID
pkill -f server.py

日志与文本

tail -f app.log
sed -n '1,120p' file.txt
grep -R "pattern" .
rg "pattern"
journalctl -u service-name
wc -l file.txt

权限与环境

chmod +x script.sh
which python3
echo $PATH
env | sort
source ~/.bashrc
uname -a

压缩与传输

tar -czf out.tar.gz dir/
tar -xzf out.tar.gz
scp file user@host:/path/
rsync -av dir/ remote:/path/

排错思路

先看:
1. 路径对不对
2. 权限够不够
3. 端口有没有占用
4. 日志里有没有直接报错
5. 环境变量是否缺失
