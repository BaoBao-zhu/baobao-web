Git

Git 日常命令与救援手册

按“看状态、保存现场、整理提交、排查历史、谨慎救援”来组织，会比记零散命令更可靠。

查看状态

git status --short
git log --oneline -5
git diff
git diff --staged
git branch -vv
git remote -v

保存现场

git stash
git stash list
git stash pop
git switch branch-name
git switch -c new-branch

整理提交

git add .
git commit -m "message"
git push
git pull --rebase
git commit --amend

排查历史

git blame file
git show COMMIT
git log -- path/to/file
git checkout BRANCH -- file
git reflog

协作前自查

推送前先确认：
1. 当前分支对不对
2. status 是否干净
3. commit message 是否清楚
4. 有没有误把临时文件带进去

危险操作提醒

慎用：
git reset --hard
git push --force
git clean -fd

先看 diff / stash / branch，
再做破坏性动作。
