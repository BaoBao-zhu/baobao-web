CPU Architecture

从五级流水到乱序执行的学习路线

这页适合作为 CPU 体系结构系列的总入口。后续可以继续加入图示、例子和你自己的理解。

Index

基础阶段 进阶阶段 建议练习 延伸阅读

1. 基础阶段

先建立最稳定的骨架：指令执行流程、五级流水、数据冒险、控制冒险、Cache 层次和基本性能指标。

关键问题

为什么流水线提高的是吞吐而不是单条指令延迟？数据前递和暂停分别解决什么问题？

推荐抓手

拿一条 load-use hazard 或 branch mispredict 例子，自己画出每个 cycle 的状态变化。

基础学习顺序建议：
ISA -> 单周期/多周期 -> 五级流水
-> hazard -> cache -> 性能分析

2. 进阶阶段

再进入乱序执行、寄存器重命名、ROB、调度窗口、Load/Store Queue 和分支预测器。重点是资源冲突和依赖解除。

学习建议：
1. 先看 in-order pipeline 的瓶颈
2. 再理解 rename / issue queue / ROB 的必要性
3. 最后再看 memory ordering 和 speculation
看 OoO 时优先抓什么

先问它如何解除假相关、如何选择 ready 指令、如何保证最终提交顺序，而不是先被大量结构名字淹没。

常见误区

把“乱序执行”误解成“程序顺序不重要”。真正不变的是架构可见结果和提交语义，不是内部执行顺序。

3. 建议练习

结合你自己的模拟器、RISC-V 工具链或课程实验，把流水线图、scoreboard 和简单预测器都亲手实现一遍。

  • 自己构造一段存在 RAW/WAR/WAW 风险的指令序列，观察不同微架构会怎么处理。
  • 实现一个简单的 bimodal predictor，对比不同分支模式下的命中率。
  • 统计某段程序的 CPI 分解，分清 stall 到底来自 cache miss、branch 还是结构冲突。

  • Hennessy & Patterson 相关章节
  • BOOM / gem5 / SimpleScalar 等开源实现
  • 你自己的课程笔记和微架构实验总结
