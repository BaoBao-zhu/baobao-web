Shell 习惯 Git 操作 调试思路

1. Shell 习惯

优先使用 `rg`、`find`、`sed -n` 这类小而准的工具组合，减少“一个命令做所有事”的复杂度。

2. Git 操作

把查看差异、保存现场、整理 commit、确认远程状态做成固定流程，会比到处查命令更高效。

3. 调试思路

先缩小范围，再查证据，再动手修改。很多时候真正节省时间的是排查路径，而不是记更多命令。
